# Backend simplification — isolated refactor branch

## Delivery boundary

Branch: `refactor/jobpilot-simplify-20260909`.

The owner explicitly requested on 2026-09-09 that this work remain outside `main`. Commit and push only this branch. Do not merge it into `main`, restart production, or replace the installed Android application without a new instruction.

## Scope

- Extract profile-scoped candidature storage, updates, saved-offer persistence and report reconciliation into `web/src/lib/candidatures.ts`.
- Replace mobile backend self-HTTP requests with direct services in the current runtime root. Keep the existing replaceable model transport and actual report/PDF persistence checks.
- Extract canonical inbox/history writers into `lib/pipeline-store.mjs`; retain the scanner's public exports, formats and locking. Saving an offer no longer imports the scanner/provider engine.
- Remove the unreachable generic run dispatcher, detached evaluator, old CLI/PDF-envelope implementation and tests exclusive to those retired paths.
- Remove four unused direct Web dependencies: `@paper-design/shaders-react`, `class-variance-authority`, `clsx`, `tailwind-merge`.
- Share candidature updates rather than maintaining different status-history/user-follow-up semantics in separate endpoints.

No Candidate data migration, new database, new model framework or authentication change is part of this refactor.

## Acceptance commands

From `web/`:

```text
npm test
npm run typecheck
npm run build
npm run qa:backend
```

`qa:backend` runs the actual built Next backend on a disposable local port against a synthetic root. It must not mock business APIs or read/write production Candidate data. Legacy internal HTTP is deliberately pointed at an unavailable address, so a regression cannot silently reach another running instance.
